# Footsteps

Fantozzi, “Fantozzi's Footsteps (Grass/Sand & Stone)”, OpenGameArt.org.
CC0. The sand recordings are used as soft grass/dirt steps; they are short
one-shots sequenced during movement rather than a continuous running loop.
<https://opengameart.org/content/fantozzis-footsteps-grasssand-stone>

Night ambience: Augmentality (Brandon Morris), “Random Sounds Samples”,
OpenGameArt.org, CC0. Recorded cricket ambience loop.
<https://opengameart.org/content/random-sounds-samples>

## Supplied project recordings

The following user-provided recordings are copied from the project's
`Sounds/zombie-sounds` folder and renamed for runtime use. Ambient vocals are
selected without repeating the same clip on one zombie, and the central audio
director limits simultaneous 3D zombie voices.

| Runtime file | In-game use |
| --- | --- |
| `zombie_groan_exhausted.wav`, `zombie_gas_groans.wav`, `zombie_trying_to_talk.wav` | Randomized, spaced ambient vocalizations while a zombie is near the player |

| `zombie_death_fall_impact.wav` | Death/fall response |
